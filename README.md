# Shubham | Data Scientist Portfolio

A personal portfolio website built with React, Vite, and Tailwind CSS to showcase my work as a Data Scientist and Generative AI Engineer.

## 🚀 Live Demo

**[View Portfolio](https://shubhammiccodes.github.io/Shubham-Portfolio/)**

## 👨‍💻 About

This portfolio highlights my experience in:
- **Generative AI & LLMs**
- **Natural Language Processing (NLP)**
- **RAG Systems**
- **Data Science & Analytics**

It includes sections for my projects, professional experience, publications, and contact information.

## 🛠️ Tech Stack

- **Frontend**: React.js (v19)
- **Build Tool**: Vite
- **Styling**: Tailwind CSS (v4)
- **Deployment**: GitHub Pages

## 🏃‍♂️ Run Locally

Clone the project and run it locally:

```bash
# Clone the repository
git clone https://github.com/shubhammiccodes/Shubham-Portfolio.git

# Navigate to the project directory
cd portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```
